What it is: A lightweight beginner/intermediate software project implementing full CRUD (Create, Read, Update, Delete) functionality using a flat file (.json or .csv) instead of a complex database.

Key Components:

CLI/Menu: Takes user input to add, view, update, search, or delete records.

Validation: Checks for unique student IDs, valid ages, and GPA bounds (0.0–4.0).

File Handler: Uses Python's native json or csv libraries to read and persist data to disk.

Where to find on GitHub: Search topic tags like student-management-system to find open-source Python implementations with ready-to-run file structures.
